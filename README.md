# Opera Restaurant & Cafe ERP

Luxury static PWA demo for Opera Restaurant & Cafe - Muscat, Oman.

## Features
- PIN login (Admin 1234, Cashier 5678, Kitchen 9999, Waiter 1111)
- POS, KDS, Tables, Accounting (double-entry), Z-Report, Loyalty
- Full Arabic RTL + Gold/Obsidian theme
- 5% Oman VAT, OMR pricing
- Offline localStorage

## Deploy
Static site - works on Vercel / Netlify / GitHub Pages.

Open index.html or deploy the root.
